Baofeng BF-888S Quick Reference

PMR446 channels, CTCSS / DCS codes, and VOX, scan and beep settings.

Channels CTCSS DCS VOX Scan Beep off

PMR446 channels

16 channels, 12.5 kHz spacing, FM, 446.00625 – 446.19375 MHz. Program them into radio positions 1–16 in this order.

Note: when scan is enabled, position 16 on the selector becomes the scan position (see Scan), so channel 16 can't be used normally.

Radio settings for each channel

  • Bandwidth: narrow (12.5 kHz)
  • TX and RX frequency the same (simplex, no offset)
  • Tones: CTCSS or DCS if wanted, otherwise off

CTCSS tones (Hz)

38 standard sub-audible tones. Everyone in your group must use the same tone. Tones do not make the conversation private; they only mute other users on the same channel.

DCS codes

Digital coded squelch, an alternative to CTCSS. Every code can be normal (N) or inverted (I), for example D023N or D023I. All radios in the group must use the same code and polarity.

VOX (hands-free transmit)

Switch VOX on or off

  1. Switch the radio off.
  2. Turn the channel knob to any channel from 1 to 5.
  3. Hold PTT and MONI together.
  4. While holding both, turn the radio on. Release when it powers up.

Repeat the same steps to switch it back off.

Set sensitivity

VOX level is set in the programming software (CHIRP or the Baofeng software), not on the radio. Too sensitive and it keys up on background noise; too low and it won't pick up your voice. Start low and raise it until normal speech triggers it. A headset or speaker-mic generally works better than the built-in mic.

Scanning

  1. In the software, set the scan option to SCAN and add the channels to scan (at least two). Leave any "FM radio" option off; this radio has none and it can stop scanning from working.
  2. Switch the radio off and set the channel knob to 16.
  3. Hold PTT and MONI together while you turn the radio on. This toggles scan on or off.
  4. With scan on, turn the knob to 16. The radio steps through the other channels and stops when it hears a signal, then resumes when it goes quiet.

Beep and voice prompts off

Beep

The beep tone is a software setting. Connect the programming cable, open CHIRP (or the Baofeng software), find the beep / beep prompt setting, set it to Off, then write to the radio.

Voice prompt (the spoken channel announcement)

  • Off for this session only: hold MONI while turning the radio on (any channel).
  • Permanently on or off: radio off, set channel knob to 10, hold PTT + MONI and turn the radio on.

Other power-on shortcuts

Radio off, set the channel, hold PTT + MONI, then switch on.

The BF-888S has no display or keypad. Frequencies, tones, VOX level and beep are all set by cable in the programming software.
